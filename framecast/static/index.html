    Trains

    Every station has a three-letter code: Leeds is LDS, London King's Cross is KGX. Search for your station on nationalrail.co.uk to find its code.

    Free from the Rail Data Marketplace (raildata.org.uk). Sign up, subscribe to Live Departure Board, and copy the consumer key from its Specification tab.

    Buses

    Find your stop on buses.co.uk. The number at the end of its page's address is the code, as in buses.co.uk/stops/149000006934. Add up to three, separated by commas, say for both directions.

    Without a key you'll see timetabled times. For live times, register for a free key with the Bus Open Data Service at data.bus-data.dft.gov.uk; it's shown in your account there.

    The first time, the Pi downloads your region's timetable, which takes a few minutes. It's refreshed weekly.

    Traffic

    The drive starts from your postcode above. Get a free key at developer.tomtom.com.

    Spotify settings

    1. Make a Spotify app

    1. Go to developer.spotify.com, sign in and open the Dashboard. Choose Create app; any name and description will do.
    2. Under Redirect URIs, add exactly, and tick Web API.
    3. Open the app's Settings and copy its Client ID here.

    Spotify only lets personal apps work for accounts with Premium.

    As Spotify names it.

    2. Connect your account

    1. Press Connect and choose Agree on Spotify's page.
    2. You'll end up on a page that won't load, with an address starting http://127.0.0.1. That's expected: copy the whole address from the address bar.
    3. Come back here, paste it below and press Finish.

    If the Spotify app opens instead of a web page, do this step on a computer.

      Share from your phone's share menu

      iPhone (Shortcuts app)

      1. Open Shortcuts, tap +, and name the shortcut Send to Frame.
      2. Tap the ⓘ button and turn on Show in Share Sheet. Set it to receive URLs and Safari web pages.
      3. Add the action Get Contents of URL. Set the URL to , method POST, request body JSON, and add a field url = Shortcut Input.
      4. Add Show Notification with the Contents of URL.

      Android (HTTP Shortcuts app)

      1. Install HTTP Shortcuts from the Play Store.
      2. Create a variable called link (type Static) and tick Allow receiving value from Share dialog.
      3. Create a shortcut named Send to Frame: method POST, URL , body type Custom text, body {link} (insert the variable).
      4. Under Response handling, choose to show the response as a toast. Under Advanced, set the timeout to 90 seconds.
      5. Now Share → HTTP Shortcuts → Send to Frame from any app.

      Either way, your phone needs to be on the home WiFi.
